# 2026-10-15 开发记录

产品版本保持 v0.1.3；尚未发布。

- 内置帧率方案的「需管理员授权」统一改为「需管理员身份运行」，英文同步。
- 「HUD 数据提示」左下角增加「此数据不再提示」。只永久屏蔽勾选时当前窗口已列出的变量，其他变量仍可提示；表达式错误按具体方案和表达式区分。
- 偏好独立存储，重启后继续生效，也不会被打开的设置编辑器覆盖。一般关闭仍只确认当次故障。

本轮在 Windows 上通过托管构建与 52 项检查。共享提示逻辑在 Windows 完成持久化及实际 Avalonia 对话框回归；macOS 原生构建、GUI 和 DMG 尚未重新验证。

- 常驻轮播新增「向上翻滚」，在固定窗口内滚动胶囊内容；新配置默认使用翻滚，已有动画设置保持不变。
- 「HUD 内容与数据」新增触发规则，支持阈值、取值变化和由假变真；按实例独立配置冷却并推进轮播队列，仅非持续显示时生效。
- 「显示与位置」新增热区开关、九宫格位置、宽高、偏移、停留时间及推进轮播选项；保留原有默认 40 px 高度。

本批仍仅在 Windows 上进行托管构建和检查，未验证真实 Mac、刘海屏、多显示器或 DMG。Windows 媒体采集器与全局快捷键未移植到 macOS。
